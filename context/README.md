# Context corpus for `retrieve_context`

Drop your real CV and past cover letters here as `.md`, `.txt`, or `.docx` files. This whole
directory is gitignored except this file and `example/` — nothing you put here gets pushed.

If this directory has no real files directly in it, the Writer agent falls back to the fake
example corpus in `example/`, so the pipeline still runs end to end without your real documents.
